<h1>Descrição do projeto</h1>
<br>
<p>Este projeto é uma lista de compras interativa desenvolvida com JavaScript, HTML e CSS. Seu objetivo é simplificar as compras no supermercado: em vez de usar a calculadora, você pode listar os itens, acompanhar o valor total em tempo real e modificar a lista a qualquer momento.</p>
